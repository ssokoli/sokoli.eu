# sokoli-content

Source material for a personal website.

- `data/`: publications, projects, career, teaching, talks and screen credits
- `texts/journal/`: original posts
- `texts/notes.json`: short-form writing
- `assets/`: photographs, covers, project images, posters and related media
- `catalogue/visual-assets.csv`: image index (category, title, file, year)

Image paths in the records are relative to the website root.
