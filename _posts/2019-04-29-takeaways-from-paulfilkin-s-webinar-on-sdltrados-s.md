<p>Takeaways from @paulfilkin's webinar on @sdltrados Studio #Subtitling app (to be launched tonight)<br>
1. An editing, not an authoring tool. Cannot touch timings or merge/split #subtitles <br>
2. It offers all MT TM functionalities plus video preview &amp; subtitle format support (a few)</p>
{% endraw %}

{% raw %}
<p>3. It is great for TQA reports (wish I had this, instead of filling-in complex forms in .doc) Seems to cater for all kinds of error categories (even timing-related errors, even if you can't edit them)<br>
4. Seems a useful tool for videos which accompany text, e.g. help videos</p>
{% endraw %}

{% raw %}
<p>5. Probably not for films/artistic AV products, but one could always test and see (esp. with very basic repetitive dialogue)<br>
6. Imho, a missing function is split/merge subs. Timing can b done w/ specialized s/w. But even with a great template, you need to split/merge to translate</p>
{% endraw %}

{% raw %}
<p>7. @paulfilkin talks at 350 wpm but is happy to repeat info. He is the rare type of presenter to answer ALL questions. Thank you, Paul!</p>
