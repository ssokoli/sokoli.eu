<p>SDL's new app "Studio Subtitling" was presented yesterday by @paulfilkin.<br>
Here is my brief list of takeaways:</p>
<p>1. It is free with SDL Studio 2019.<br>
2. An editing, not an authoring tool. The user cannot edit timings nor merge/split subtitles. (You can, but only for the TM. Merging not recommended, as it creates an empty time-code).<br>
3. It offers all MT TM functionalities plus video preview &amp; subtitle format support (webVTT, Spruce STL and SBV. SRT is available already).<br>
4. It is great for QA reports (I wish I could use this, instead of filling-in complicated .doc forms) Based on Jan Pedersen's FAR model, it seems to cater for all kinds of error categories. The users can even flag timing-related errors, despite the fact that they cannot edit them (see point 2 above).<br>
5. Seems useful for videos which accompany text, e.g. help videos for products in web pages or online courses.<br>
6. Probably not useful for subtitling films/artistic AV products. But one could always test and see (esp. with very basic repetitive dialogue). Definitely useful for their TQA, though (see point 4)<br>
7. Imho, a missing function is splitting/merging subs. Initial timing is done with specialized subtitling software, but even with a great template, you need to be able to split/merge when editing.</p>
