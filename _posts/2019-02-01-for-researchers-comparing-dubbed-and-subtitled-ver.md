<p>For researchers comparing #dubbed and #subtitled versions of the same show and finding inconsistencies in terms etc. Pls have in mind the reality of the profession and the turnaround times. The deadlines for sending final consistency checks sometimes do not allow for it.</p>
{% endraw %}

{% raw %}
<p>You get the subtitled version, sign it off, all good. Then you get the consistency sheet and discover the terms are different (even though equally valid). It would be easier to correct the subtitles rather than the dubbing, but the file is already sent, can't be corrected.</p>
{% endraw %}

{% raw %}
<p>Your only hope is that the dubbing studio will correct the term (more time-consuming) but you never know until the show is on air.</p>
{% endraw %}

{% raw %}
<p>Watching the dubbed version with subtitles in the same language is something that only researchers and weirdos do (or weird researchers), right? Would inconsistencies affect the "normal" viewing experience? I can't see any reason why</p>
{% endraw %}
