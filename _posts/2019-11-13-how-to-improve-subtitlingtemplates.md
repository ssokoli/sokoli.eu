<p>How to improve #subtitlingtemplates? <br>
1. Correct timing / improved readability: <br>
- Complete meaning in every subtitle when possible<br>
- No unnecessary one-word subs or split sentences<br>
- Respecting shot changes but not sacrificing readability<br>
- No subs less than 1min<br>
- Rhythm!</p>
{% endraw %}

{% raw %}
<p>2. Verbatim text:<br>
Templates should not be used for SDH, but created specifically for translation purposes. And if they are not shown to any viewers, readability issues will not apply to them.<br>
It's the translator/subtitler's job to condense the text.</p>
{% endraw %}

{% raw %}
<p>3. No #oversubtitling:<br>
Viewers deserve to enjoy the rest of the image. Non-verbal elements (e.g. exclamations), repetitions, recoverable from audio, should be omitted. Standard subs are not to replace proper SDH nor to cover the need for watching on mute or in noisy places</p>
{% endraw %}

{% raw %}
<p>...If you can't hear the audio for some reason, you'll miss all the plot-relevant sounds anyway. <br>
Subtitlers and viewers need to trust each other mutually, and to consider each other competent enough<br>
#subtitleomission</p>
{% endraw %}

{% raw %}
<p>4. Proper annotations. <br>
The following are especially necessary when templates are used for #pivotsubtitling:<br>
- Formality level<br>
- Singular/plural use of "you"<br>
- Character's gender<br>
- Cultural and intertextual references</p>
{% endraw %}

{% raw %}
<p>5. All on-screen text should be included in the template. It's up to the translator to decide whether it is to appear in the subtitles or not (Important for the plot? Redundant because it is exactly the same?)</p>
{% endraw %}
