<p>Translating intentionally weird dialogue is a tricky aspect of #subtitling. E.g. unexpected formality levels, meaningful pronunciation errors or made-up words. Some choices might confuse viewers: Is this an error, or a deliberate part of the story?</p>
{% endraw %}

{% raw %}
<p>Hopefully viewers trust that any peculiarities in the translation are intentional, not mistakes. <br>
The only way subtitlers can gain this trust is by consistently providing impeccable quality.</p>
{% endraw %}

{% raw %}
<p>As a reviewer, I've caught myself not trusting the subtitler, immediately correcting the "weird" rendering, only to find out later that this was intentional.</p>
{% endraw %}
